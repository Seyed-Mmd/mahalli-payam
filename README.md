# پیام محلی

سامانهٔ دسترسی محلی به پیامک‌ها، مخاطبین، فایل‌ها و گالری گوشی اندرویدی. سایت برای حساب‌ها و مدیریت دسترسی است؛ پنل داده‌های گوشی روی شبکهٔ محلی خود گوشی اجرا می‌شود.

## آفلاین و PWA

- سایت یک وب‌اپ قابل نصب (PWA) است. پس از بازکردن سایت با اینترنت، فایل‌های ظاهری و صفحهٔ آفلاین در کش مرورگر ذخیره می‌شوند.
- برای دیدن اطلاعات گوشی، لپ‌تاپ را به هات‌اسپات گوشی وصل کن و نشانی‌ای را که اپ اندروید نشان می‌دهد باز کن. خود این اتصال محلی به اینترنت نیاز ندارد.
- وقتی اپ اندروید به اینترنت و هاست دسترسی دارد، وضعیت حساب را در شروع سرویس و سپس در فاصله‌های تصادفی حدود ۸ تا ۲۰ دقیقه بررسی می‌کند. اگر هاست صریحاً حساب یا دستگاه را غیرفعال اعلام کند، خواندن داده‌ها قفل می‌شود و پنل پیام دسترسی لغوشده نشان می‌دهد.
- اگر اینترنت یا هاست در دسترس نباشد، بررسی انجام نمی‌شود و پنل محلی با آخرین وضعیت تأییدشده ادامه می‌دهد؛ محدودیت ۳۰روزه ندارد. در نتیجه، لغو دسترسی تا زمانی که گوشی دوباره بتواند به هاست وصل شود دریافت نمی‌شود.
- پوستهٔ PWA آفلاین باز می‌شود و راهنمای ورود به نشانی محلی گوشی را نشان می‌دهد. پنل گوشی همچنان از خود گوشی و شبکهٔ هات‌اسپات بارگیری می‌شود.
- فایل صفحهٔ محلی گوشی هم در حافظهٔ مرورگر تا ۲۴ ساعت قابل استفادهٔ مجدد است؛ فهرست‌ها و محتوای پیام‌ها/رسانه‌ها هنگام اتصال از گوشی خوانده می‌شوند.
- محتوای پیامک، مخاطبین، فایل و گالری به هاست فرستاده نمی‌شود. هاست فقط نام کاربری، هش رمز، کد جفت‌سازی، وضعیت حساب و شناسه/توکن دستگاه را نگه می‌دارد.

## نصب سایت روی هاست PHP اشتراکی

نیازمندی‌ها: PHP 8.1 یا جدیدتر، افزونهٔ `PDO SQLite` فعال، HTTPS برای سایت هنگام اتصال اولیه، و امکان نوشتن PHP در پوشهٔ بالاتر از ریشهٔ عمومی سایت.

1. فایل‌های پوشهٔ `website/` را روی هاست بارگذاری کن.
2. سایت را باز کن و به `install.php` برو.
3. نام کاربری و رمز مدیر را در نصب‌کننده وارد کن. رمز باید دست‌کم ۱۲ نویسه باشد. فایل SQLite و مدیر اولیه خودکار ساخته می‌شوند؛ نیازی به ساخت دستی دیتابیس نیست.
4. از صفحهٔ ورود سایت با همان نام کاربری و رمز وارد شو. نصب‌کننده پس از ساخت دیتابیس قفل می‌شود.
5. از پنل مدیریت کاربر بساز، یا در صورت تمایل ثبت‌نام عمومی را باز کن. ثبت‌نام عمومی در نصب اولیه بسته است.

فایل دیتابیس در پوشه‌ای بالاتر از `DOCUMENT_ROOT` قرار می‌گیرد تا از وب مستقیم در دسترس نباشد. اگر هاست اجازهٔ نوشتن در آن مسیر را ندهد، باید دسترسی نوشتن را از پشتیبانی هاست بگیری یا نصب را در مسیری انجام دهی که PHP امکان ساخت پوشهٔ خصوصی داشته باشد. اگر `PDO SQLite` روی هاست فعال نباشد، نصب‌کننده پیام خطا می‌دهد.

## ساخت APK با GitHub Actions

1. پروژه را در مخزن GitHub قرار بده.
2. آدرس پیش‌فرض API برابر `https://s53.ir/api.php` تنظیم شده است. اگر فایل `api.php` را در پوشه‌ای غیر از ریشهٔ دامنه گذاشتی، هنگام اجرای workflow آدرس کامل همان فایل را وارد کن.
3. در **Actions → Build Android APK → Run workflow**، ساخت را اجرا کن. با push تغییرات اندروید هم workflow خودکار اجرا می‌شود.
4. artifact به نام `mahalli-payam-debug-apk` را دانلود و فایل `app-debug.apk` را استخراج کن.
5. APK را با نام `mahalli-payam.apk` در `website/downloads/` قرار بده و آن پوشه را به هاست بارگذاری کن تا دکمهٔ دانلود سایت کار کند.

این APK با کلید debug ساخته می‌شود و برای نصب شخصی است. اگر کلید امضای debug بین دو ساخت متفاوت شود، ممکن است نصب نسخهٔ جدید نیازمند حذف نسخهٔ قبلی و جفت‌سازی دوباره باشد.

## استفاده

1. مدیر از پنل سایت حساب کاربری می‌سازد یا ثبت‌نام عمومی را موقتاً فعال می‌کند.
2. کاربر با همان مسیر عادی ورود می‌کند. پس از تأیید حساب، از پنل یک کد اتصال ۱۰ دقیقه‌ای می‌گیرد.
3. کد را در اپ اندروید وارد می‌کند و مجوزهای گوشی و رمز محلی حداقل ۸ رقمی را تنظیم می‌کند.
4. هات‌اسپات گوشی را روشن می‌کند، لپ‌تاپ را به آن وصل می‌کند و در اپ «شروع پنل محلی» را می‌زند.
5. لپ‌تاپ را به همان هات‌اسپات وصل می‌کند. PWA نصب‌شده یا مرورگر را باز می‌کند و نشانی محلی روی گوشی را وارد می‌کند.

پنل گوشی پس از پنج دقیقه بی‌فعالیتی دوباره رمز می‌خواهد. اپ اعلان دائمی سرویس را نشان می‌دهد تا پنل در زمان قفل بودن صفحه هم فعال بماند. برای پوشه‌ها و گالری فقط API خواندنی ارائه می‌شود؛ هیچ مسیر حذف یا ویرایش وجود ندارد.

## محدودیت‌های اندروید

- اندروید برای پیامک، مخاطبین و رسانه‌ها مجوز سیستمی می‌خواهد؛ اپ نمی‌تواند آن‌ها را بی‌صدا فعال کند. مجوز `READ_SMS` از نوع محدودشده است و ممکن است نصب‌کنندهٔ اندروید برای اجازه‌دادن به آن محدودیت داشته باشد.
- مجوز «همهٔ فایل‌ها» را باید از تنظیمات گوشی فعال کرد. اندروید با وجود این مجوز هم پوشهٔ خصوصی اپ‌های دیگر مانند `Android/data` را در اختیار برنامه نمی‌گذارد؛ این مجوز در سطح سیستم گسترده است، اما خود پنل فقط خواندن و دانلود را پیاده می‌کند.
- RCS و پیام‌های WhatsApp/Telegram پیامک اندروید نیستند.
- از هات‌اسپات شخصی استفاده کن. روی شبکهٔ عمومی پنل محلی را باز نکن.
